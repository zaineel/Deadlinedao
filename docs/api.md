# API reference

Generated by reading every `app/api/**/route.ts`. `GET /api` returns a machine-readable index, but this document is more complete. Errors are generic JSON `{ "error": "..." }`; validation failures are 400 `{ "error": "Invalid request", "issues": [{field, message}] }`.

## Authentication kinds

| Kind | How it is sent | Failure |
| --- | --- | --- |
| public | nothing | n/a |
| admin key | header `x-admin-key: $ADMIN_API_KEY` (`lib/auth/admin.ts`) | 401 wrong key, 503 if `ADMIN_API_KEY` unset |
| session | wallet sign-in token as `Authorization: Bearer <token>` or the `dd_session` httpOnly cookie (`lib/auth/session.ts`); the wallet comes from the session | 401 |
| cron secret | `Authorization: Bearer $CRON_SECRET` (constant-time compare) | 401, also when `CRON_SECRET` is unset |
| wallet-signed | an ed25519 signature inside the request body, verified server-side | 401 |

Feature flags (`FEATURE_<NAME>=true`, default off): when a flag is off its routes answer 404 `{ "error": "Not found" }`.

Rate limits are per client (`lib/rate-limit.ts`); exceeding them returns 429.

Types: `uuid` is a UUID string; `wallet` is a base58 Solana address; `lamports` are integers; SOL amounts have at most 4 decimals.

## Sign-in (wallet sessions)

Sessions are needed by the disputes, orgs and push features and by `GET /api/proofs`.

| Route | Auth | Body | Response |
| --- | --- | --- | --- |
| `POST /api/auth/nonce` | public | `{wallet}` | `{nonce, issuedAt, message}`. The wallet signs `message`. Nonce is valid 5 minutes. 503 if `SESSION_SECRET` is unset. |
| `POST /api/auth/verify` | public | `{wallet, nonce, issuedAt, signature}` | `{token, wallet, expiresAt}` and sets the `dd_session` cookie (24 h). 401 if invalid or expired. |
| `GET /api/auth/session` | session | none | `{wallet}` |
| `POST /api/auth/logout` | public | none | `{ok: true}`; clears the cookie |

## Goals

| Route | Auth | Flag | Request | Response |
| --- | --- | --- | --- | --- |
| `GET /api/goals?wallet=` | public | | `wallet` query | `{goals: Goal[]}` for that wallet, newest first |
| `POST /api/goals/create` | public, rate limited 10/min | | `{title(1-100), description(1-1000), deadline(future ISO date), category('learning'|'work'|'health'), stakeAmount(>0, <=1000, 4 dp), walletAddress}` | `{success, goalId, transaction(base64, unsigned user->escrow transfer), escrowAddress, message}`. Goal is stored as `pending_validation` with `stake_tx_signature='pending'`. In demo mode: `{success, goalId, demoMode:true, message}` and no transaction. |
| `POST /api/goals/confirm` | public | | `{goalId, signature}` | Verifies on-chain that `signature` is a transfer from the goal's wallet to escrow of at least the stake, and that the signature is unused; then activates the goal: `{success, goal, message}`. 404 unknown goal, 409 not awaiting confirmation or signature reused, 400 not verifiable yet. `demo_tx_*` signatures are accepted only in demo mode. |
| `GET /api/goals/[id]` | public | | | `{success, goal}` or 404 |
| `PUT /api/goals/[id]` | admin key | | `{status: 'active'|'pending_validation'|'completed'|'failed'}` | `{success, goal}`. Raw status edit; moves no money. |
| `POST /api/goals/share` | session, rate limited 30/min | `push` | `{goalId, share: boolean}` | `{success, shared}`. Toggles public sharing of the caller's own `completed` goal (the `/p` page). 404 if not found, not yours or not completed. |

## Proofs and uploads

| Route | Auth | Request | Response |
| --- | --- | --- | --- |
| `POST /api/upload/proof` | public, rate limited 10/min | multipart form: `file` (JPEG or PNG, <=10 MB, content sniffed), `goalId` (uuid) | `{success, url, fileName, fileSize, fileType}`; `url` is under `CLOUDFLARE_R2_PUBLIC_URL`. This replaces the removed `/api/upload/presigned`. |
| `POST /api/proofs` | wallet-signed, rate limited 5/min | `{goal_id, text_description(1-5000), image_url?(https, must be under the R2 public URL), timestamp(ms), signature(base64)}`. The wallet signs `DeadlineDAO:submit-proof\ngoal:<id>\nts:<timestamp>\nhash:<hash>`, where the hash covers the text and image URL; the timestamp must be within 5 minutes. | Goal must be `active` and within deadline plus 7 days. Response includes `success, proof, validation, goal_status` and by verdict: `approved` -> `goal_status:'completed'` with `payout` (200; 202 with `payout.status:'unconfirmed'` if the transfer is ambiguous; 502 and the goal reopened if it definitively failed); `rejected` -> `failed`, or `rejected_appealable` when disputes are on; `needs_review` -> `pending_validation` (goes to the admin queue). |
| `GET /api/proofs?goal_id=` | admin key, or session whose wallet owns the goal | `goal_id` query | `{success, proofs, count}`. 404 for missing or not yours. |

## Admin (admin key)

| Route | Request | Response |
| --- | --- | --- |
| `GET /api/admin/trigger-rewards?deadline=YYYY-MM-DD` | `deadline` query | Preview: `{preview:true, deadline, stats, distribution[], canDistribute, pendingAppeals, note}` |
| `POST /api/admin/trigger-rewards` | `{deadline: 'YYYY-MM-DD'}` | Runs Phase 2. `{success, message, stats, distribution:{successfulPayouts, alreadyDistributed, failedPayouts, unconfirmedPayouts, ...}, rewards[], errors, solanaExplorer[]}`. 409 while appeals are unsettled. Idempotent (claim-before-send). |
| `GET /api/admin/review` | | `{success, count, items:[{goal, proof}]}` goals awaiting manual review with the AI verdict |
| `POST /api/admin/review` | `{goalId, decision:'approve'|'reject'}` | approve: `{success, goalId, status:'completed', payout}` (202 if unconfirmed, 502 if the transfer failed and the goal returned to the queue); reject: `{success, goalId, status:'failed'}`. 404 unknown, 409 not awaiting review or already processed. |
| `POST /api/admin/payouts/reconcile` | optional `{payoutId?: uuid}` (strict) | `{success, checked, finalized, released, waiting, manual, errors, outcomes[]}` |
| `GET /api/admin/disputes` | (flag `disputes`) | `{success, count, items}` open disputes |
| `POST /api/admin/disputes` | (flag `disputes`) `{disputeId, decision:'overturn'|'uphold'}` | resolves an appeal; no-op if already resolved |
| `POST /api/admin/org-matches` | (flag `orgs`) none | `{success, summary}` runs the sponsor-match sweep |

## Disputes (flag `disputes`)

| Route | Auth | Request | Response |
| --- | --- | --- | --- |
| `POST /api/disputes` | session, rate limited 5/min | `{goalId, reason(10-1000), extraImageUrl?, bondSignature}` | Verifies the 5% bond transfer on-chain and opens the dispute (goal becomes `disputed`). 404 goal not found. See `docs/features/disputes.md`. |
| `GET /api/disputes` | session | | The caller's disputes, plus `appealable` goals with `bondAmount`, and `escrowAddress` (null when nothing is appealable). A 404 means the flag is off. |

## Organizations (flag `orgs`, all session auth)

Org-admin routes return 404 to non-admins so ids cannot be probed. See `docs/features/orgs.md`.

| Route | Rate limit | Request | Response |
| --- | --- | --- | --- |
| `GET /api/orgs` | | | `{organizations:[{id, name, isAdmin, inviteCode (admins only), membership, program}]}`; balances only for admins |
| `POST /api/orgs` | 5/hour | `{name, additionalAdminWallets?[<=9], matchRatePercent(0.01-100), perMemberCapSol, windowStart, windowEnd}` | 201 `{success, id, name, inviteCode}` |
| `POST /api/orgs/join` | 10 per 10 min | `{inviteCode}` | `{success, orgId, orgName, alreadyMember}`; 404 invalid code |
| `GET /api/orgs/[id]/members` | | | Own `membership`; admins also get `headcount` |
| `PUT /api/orgs/[id]/members` | 30/hour | `{consent: boolean}` | `{success, consent}`: a member sets their own aggregate-stats consent |
| `GET /api/orgs/[id]/fund` | org admin | | `{escrowAddress}` |
| `POST /api/orgs/[id]/fund` | org admin, 20/hour | `{signature}` | Verifies the admin's transfer to escrow and credits the pool; 409 reused signature or window ended, 503 not yet verifiable |
| `GET /api/orgs/[id]/stats` | org admin | | Aggregate stats over consenting members, suppressed below the minimum group size; never wallets or goal text |
| `POST /api/orgs/[id]/withdraw` | org admin, 5/hour | none | Withdraws the unspent pool to the admin's wallet after the program window ends: `{success, amountLamports, signature}`; 409 with a reason otherwise, 502 on a failed transfer (balance kept) |

| Route | Rate limited | Request | Response |
| --- | --- | --- | --- |

## Cron (cron secret, `GET`)

Scheduled in `vercel.json`; see `docs/admin.md`.

| Route | Flag | Response |
| --- | --- | --- |
| `/api/cron/expire-goals` | | `{success, checked, failed}`; fails `active` goals past deadline plus 7 days |
| `/api/cron/finalize-appeals` | | `{success, checked, failed}`; fails `rejected_appealable` goals whose window closed |
| `/api/cron/deadline-reminders` | `push` | `{success, due, sent, skipped}` |
| `/api/cron/org-matches` | `orgs` | `{success, summary}` |

## Not present

There are no team routes on `main` (the `teams` flag exists in `lib/config/features.ts` but no route uses it yet), and there is no `/api/upload/presigned`.
